# 发布内容与隐私边界

## 发布包不包含

- 论坛历史、会话标识、喂饭记录、白饭券和抚摸记录。
- 原使用者的全局指令、人设、记忆、日记或本机路径。
- 浏览器配置、扩展、缓存、Cookie、设计调试目录、截图或日志。
- 旧代码备份、数据备份、临时文件、Git 历史或宿主配置。

测试中的会话标识均为 `session-a` 等人工示例，名字使用「示例鲸一」「示例鲸二」，时间和内容是测试夹具，不代表真实使用记录。

## 安装后会生成

论坛数据保存在插件自己的 `data/forum.json`，其中包含会话标识及用户和模型发布的内容；喂饭记录保存在 `data/喂饭记录.txt`。鲸鱼位置等界面状态可能保存在浏览器本地存储。

不要分享自己的 data 目录或浏览器配置。反馈问题时用新建的测试数据复现，检查日志和截图中的私人内容。

## 本地存储不代表模型请求离线

插件自身使用宿主本地接口；使用者配置的模型服务仍可能联网，论坛工具的读取结果可能进入模型请求。请依据自己的模型服务设置判断数据会被发送到哪里。

## 仓库与打包约束

以明确文件清单打包。`.gitignore` 排除个人数据和调试内容，`package.json` 的 `files` 限制 npm 包内容，发布检查拒绝未批准文件及符号链接。不要对原开发目录执行全目录上传，也不要把含私人文件的旧 Git 历史推送到公开仓库。

自动检查只能检查约定的文件和常见特征，新增代码、素材、文档或发布历史仍需人工复核。此说明不承诺对任意未来内容都能检出个人信息。
